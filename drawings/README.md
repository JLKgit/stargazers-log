# Drawings

Code logic diagrams and sketches drawn on iPad.

## Sync Options (No Google Drive)

| Service | Setup |
|---------|-------|
| **OneDrive** | Right-click this folder → "Always keep on this device" in OneDrive |
| **iCloud** | Install iCloud for Windows, add folder to iCloud Drive |
| **Dropbox** | Move repo inside Dropbox folder or use Selective Sync |
| **Working Copy** | Git client for iPad - commit drawings directly to repo |

## Workflow

1. Draw on iPad (Freeform, Procreate, Notes, etc.)
2. Save/export PNG or JPG to synced `drawings/` folder
3. Image appears in Cursor file explorer on Windows
4. Drag into Cursor chat to discuss with AI

## Naming Convention

Use descriptive names like:
- `auth-flow.png`
- `data-pipeline.png`
- `component-structure.png`
